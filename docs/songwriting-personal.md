## 本轮实现

原有歌曲书架、创建、封面、MiniMax Music 免费/付费、ACE-Step、音乐 App 联动继续使用 `apps/SongwritingApp.tsx`。写作页由独立 `components/song/SongwritingStudio.tsx` 承接，可切换浅绿月亮小羊和浅蓝海洋小狗；主题偏好保存为原有 assets 中的 `songwriting:theme`，不增加数据库表或后端。

### 一份聊天记录

用户与角色讨论直接写原有 messages，保留 user/assistant、原文和自动生成的消息 ID。metadata.source 为 songwriting，songId 标记当前作品。写歌页默认筛选本曲，也能查看当前角色完整私聊；群聊与其他角色消息不混入。没有写歌独立消息计数器、总结器或讨论摘要。

请求前重新读取角色、普通聊天有效范围和水位，复用 buildChatRequestPayload 的角色/用户/世界书/日程/情绪/记忆召回及历史处理。appPrompt 只替换场景规则、输出协议和当前歌曲资料；使用角色默认对话 API，URL/Key/Model 整套选择。不会把全部旧记录绕过范围送给模型。

songwriting-history-updated 接入 OSContext 已有 historyChanged 和 Chat 的刷新监听；只调用原有 processNewMessagesWithAutoArchive，不修改记忆核心、阈值、批次、权重或水位逻辑。事件不触发聊天模型的第二次回复。原生管线继续负责同角色的串行与去重。

### 确认后保存

支持单句、连续段落、整首候选。段落默认从所选句开始处理同类型的连续歌词；建议选择段落首句，选择末尾则新增指定段落。可指定句数和要求；整首不强制固定模板。聊天也可提出按连续范围替换的候选。

候选保存在 SongSheet.lyricProposal，刷新可恢复。接受前可预览、手改、稍后查看、取消或重新生成。明确说“就用这版”等且模型正确引用当前候选 ID 时，也可确认保存；含糊的“好”不自动操作。单句候选不得越过目标范围，段落候选不能修改其他段落；截断/无效 JSON 报错，不写空结果。

正式修改在 songs/messages 同一个 IndexedDB 事务中写歌词、lyricRevisions 和一张折叠修改卡。一次改整段也只有一张。无变化不写卡，失败全事务回滚；操作 ID 防止重试重复。候选指纹阻止覆盖后来更新的歌词，版本恢复作为新修改。手动编辑只在明确保存时提交一次。

角色回复与对应候选也在同一事务落库，避免网络重试后聊天正文与候选不一致。用户消息使用 saveMessageOnce，不因重试重复记录。

歌词定稿独立于出歌，完成卡以已完成歌词指纹去重。卡片正文含完整可读修改内容，聊天与原有记忆格式化均可读，不需要新记忆规则。

### 数据与作品

新增字段均为 SongSheet/SongAudio 的可选字段，沿用原有歌曲和 assets 备份。保留旧评论作为只读原文，不迁移、不重复写入聊天。用户本身没有使用旧写歌 App，无需历史迁移任务。

生成音频保留 audioVersions，记录对应 lyricRevisionId；原生成页可切换既有音频版本，音乐 App 继续使用选定音频。不修改 MiniMax/ACE-Step 服务实现或原有配置。

## 海绵原创出歌

写作页新增「海绵出歌」：自由填写创作设想或让角色填写，再按最终歌词、曲风、情绪和可读讨论整理制作说明；使用角色默认聊天 API 和原有上下文管线，不改写歌词，不调用记忆总结，不自动提交海绵。角色填写的设想写入原日常聊天；整理后的制作说明留在歌曲中，可预览修改。

歌词、歌名、曲风、情绪或自由设想变化会使已有说明过期，需重新整理；编辑制作说明本身不触发额外模型调用。提交一次生成一首，先持久化提交标记和输入快照，再调用独立 Worker；超时或关闭页面后需到官网核对、填任务 ID 恢复或明确确认未受理，不自动重试扣积分。已完成/失败的旧任务保留在历史快照，不随新歌词变化。

连接密钥与 Cookie 仅在页内内存，不进入歌曲、聊天、备份或仓库。仅个人网页域名允许跨域访问独立 Worker；不改全局代理。查询与获取成品地址都由用户点击，生成完成并成功获取地址后出一张完成卡，多次获取不重复。当前成品以有时效的外链播放/下载，需要时可重新取地址，尚未写入原音乐 App 的本地音频版本。

「专属歌声」预填官网第五张固定朗读台词，复用角色 MiniMax 配置生成朗读；试听后可明确点击，将当前音频文件及其生成时的台词直接上传独立 Worker 注册音色，不需要外放录音。音色记录存入每角色独立 assets，沿用原备份；先事务写入 submitting 标记再上传，超时转 unknown 禁止自动重发，同角色跨页面同时提交只受理一次。手动查询 ready 后绑定，出歌页读列表时优先选择该音色。旧记录作为历史保留，凭证不进入存储。已有音色可以填 ID 查询绑定。真实文件上传/注册仍待用户联调，测试通过不保证歌声相似。保留原 MiniMax Music/ACE-Step 与原试听入口。没有翻唱、旋律导入、发布功能。

## 2026-11-16 界面与音迹关键词

- 歌词本「手动编辑 / 保存」同窗编辑歌名与歌词，沿用同一事务保存，歌名/歌词任一已被其他页面修改则不覆盖。旧录音、谱曲、任务与历史保留；制作说明指纹会检测改名后的过期。
- 风格「自由发挥」与情绪「根据讨论自由发挥」不预设标签，歌词、谱曲、制作说明均明确读取讨论与设想。
- 工作室「出歌与成品」集中海绵、专属歌声、其他方式/试听；歌词本完成后可直接进入成品、导入与下载。原 MiniMax/ACE-Step 等能力保留。
- 个人歌曲列表只显示歌名/歌手。长按打开底部操作面板：删除（仅当前歌单）、分享给角色（再选角色）、加入歌单（再选个人歌单、按录音身份去重）。滑动取消长按，长按释放不播放。
- 音迹列表顶部「聊天关键词关联」默认关闭，保存在现有 assets，随原备份恢复。匹配仅取本轮待回复的用户普通聊天文字，不读取人设、世界书、记忆，不匹配自动应用记录或音迹卡片。歌手只匹配保存的全名（不扩展昵称），注入音迹已存歌名；歌名匹配带入已保存详情，不触发重新识别或额外模型调用。
- 召回内容保存在原 messages 的 system/text 卡片，`metadata.source=song-archive-recall`，具体资料可展开/滚动。原聊天上下文与原有记忆总结自然读取，不改记忆提取/召回核心。首次资料放在本次动态尾段，次轮读取已存聊天卡，不更改稳定提示或缓存断点。
- 按角色 + 歌手全名 / 歌曲 ID 去重；读取可靠原宫殿总结水位与完整持久聊天，不能把手动截断上下文当总结。未总结卡不重复保存；总结后再次提到可重发。`saveMessageOnce` 的交付键沿用上次同类卡 ID，防同轮重试/并发重复。无总结水位的旧系统保守保留去重，不猜测已总结。
- 音迹列表只按 asset 前缀读取档案，避免每次匹配加载相册/音频等无关素材；未更改数据库版本或任何媒体内容。

## 2026-11-16 单一出歌弹窗与逐句人声曲调

替代上方「出歌与成品」独立页：歌词本「出歌 / 成品 / 下载」直接打开原有的四服务商弹窗。海绵操作都在此弹窗，MiniMax / ACE-Step 同一弹窗及视觉 token；音色生成仍独立「专属歌声」。只移动原出歌控件、统一 CSS，不改海绵制作提示词、MiniMax/ACE-Step 提示词或提交逻辑。MiniMax/ACE-Step 的成品播放、音频版本、下载、歌单封面入口也在弹窗里；保留旧预览页。

只有「创作对话」显示聊天历史和输入栏，歌词/谱曲仅为同一输入栏的任务选择。曲谱页只放范围、版本、五线谱、关联、试听和下载；快捷交流按钮回到这一处对话。普通讨论不写曲谱/卡片；有效旋律仍通过原 songs+messages 事务保存。

新增 `VocalPhrase`：以整句歌词对应完整人声乐句，保存 `lineId + lyricText + start/count`，允许一句占多个小节。一个汉字可跨多个音符（转音/拖腔），lyric 只标该字起点，后续音符允许省略；不按字数切分音符、不强制一字一音。ABC 可显示已标注音节与延音位。1–128 小节的完整版本可逐句逐段累积，不再强制每次八小节；C 大调、4/4、50–160 BPM 的既有音高与时值边界保留。

部分修改仅允许写所选句子/乐句，未选片段的音符原样保留；局部修改不重新设定整曲速度。每次实际改曲保留旧版及完成/调整卡。歌词生成也可读取原旋律、乐句和节奏；先曲后词且句数明确一致时按乐句顺序关联，否则用户可在曲谱页显式关联。词改动后旧曲保留，未确认的新词不冒用原句小喇叭；原句未改字但行 ID 变化可重新关联。旧八小节谱无可靠绑定，不猜它对应哪句，可整段播放并在对应面板显式绑定。

歌词本的句旁小喇叭播放完整乐句，使用本地合成、无额外模型调用。曲谱页可选单句/段落/整首试听、导出 WAV/MIDI、给 Char 试听；独立音频 API 只做原有纯客观描述，同版同范围复用，随后由 Char 决定讨论或修改。自然对话中「你自己听听第2句」也可走该路径。听感保存版本与范围，不新增记忆体系、不发送大屏系统听感卡、不改原听歌提示词。

新增移动端无付费 fixture：`song-production-browser.*` 和 `scripts/song-production-browser-check.mjs`，验证 320/390px 单弹窗、四服务商切换、句旁按钮、曲谱页无重复聊天。fixture 的谱面绘制为 UI stub；真实 abcjs 声音仍需手机验收。

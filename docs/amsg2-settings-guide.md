## 全局总开关

填写过 Worker 地址后，设置页「主动消息 2.0」卡片和全局配置面板顶部都会显示**总开关**（`ActiveMsg2GlobalConfig.enabled`，未设置时视为开启；编排在 `utils/amsgGlobalSwitch.ts`，判断统一走 `utils/amsgGlobalGate.ts`）。

- **保留配置就地暂停**：关闭总开关只把 `enabled` 存为 `false`，Worker 地址、共享密钥、主密钥、中转设置、推送方式以及各角色自己的开关与任务清单全部原样保留，恢复开启即可继续使用，不必重新填地址或重配角色。
- **本机零残留请求**：总开关关闭期间，冷启动、回到前台、第三方推送前台轮询、晚投情绪轮询、聊天与见面的活跃会话租约、记忆宫殿门牌云端通道、离开后消息与见面离开提醒的云端分支、工具与 API 凭据同步、角色上下文（`fire_pack`）上传，以及打开设置页 / 推送面板 / 角色 2.0 面板时的自动探测，一律不在后台向 Worker 或中转服务发起请求。即时对话自动回退到本机生成。
- **远端定时触发尽力暂停、绝不阻塞本地关闭**：关闭瞬间会先切断本机在途等待与定时器，再以短超时尝试通知 Worker 摘掉 Cron 定时触发并取消在途即时任务。即使 Worker 已被删除、断网或缺少 `CF_API_TOKEN`，本机暂停依然立即完成，只在界面提示云端定时触发未能同步暂停。
- **暂停期间的改动记账延后对齐**：暂停时修改工具配置、API Key 或角色资料，本地待同步标记会保留在 `localStorage` 中，不发请求也不排退避重试；暂停期间删除角色或用户空间，不阻塞删除流程，而是把角色记入本机待停用底账（`amsg2_cloud_retirements`）。重新开启总开关（或点击「连接并启用」）后，系统自动恢复定时触发，并依次补送待停用角色、订阅变化标记、云端漏收账本与待同步快照。

# 朋友圈修订与音乐管理

朋友圈信息流新增铅笔编辑、垃圾桶删除；可见范围随编辑一同设置。user 可管理所有作者动态，预览某角色时仍按该角色权限只读。赞保留姓名，评论与回复显示设备本地收发时间；赞/评论两点图标缩小。

## 两种删除

- 普通删除保存 tombstone，信息流与新浏览不再返回。实际看过者保留当时的 Seen 投影和卡片；已看内容仍可按需检索。角色只能普通删除、编辑本人最近历史里的动态，仍在自己的活动请求内决定，不额外触发模型。
- 用户真实删除物理移除原动态、浏览档案、待办事件及关联事件卡；编辑直接更新已看者档案与事件卡，不把新版本发送给未看过者。
- 两者递增配置版本，正在等待的旧活动不能提交。编辑额外校验原动态修订号。权限读取、好友范围、增量索引及完整备份沿用原路径。

真实删除只清理朋友圈原始动态、浏览记录、待办事件及关联聊天事件卡；编辑同步更新朋友圈和已浏览档案。已提取的宫殿、传统日度/月度记忆、向量与链接保持原样，用户按需手动调整。

不再生成或注入“从未发布”等长期现实校正，也不读取旧版本的校正提醒或向量撤销名单。保留旧备份字段兼容，不恢复之前已发生的数据修改。

## 音乐

歌单列表移除新建、保存、加歌操作；新建仍在音乐管理。原“歌单 / 最近 / 云盘”行增加“同步”，刷新网易云完整歌单索引并逐单保存。重复同步按歌曲身份去重；部分失败保留已保存歌单并提示重试，不回写网易云账号。

音乐管理“一键加歌”接受每行一条 HTTPS 音频直链或网易云歌曲链接，最多100条。网易云链接读取歌曲资料，直链以文件名预填；识别失败可手填。确认页允许修改歌名、歌手及逐首移除。只有确认剩余歌曲才入库；取消不写入。不下载直链音频。已导入歌曲可单独导入 LRC/TXT 歌词。

user 歌单歌曲短按播放，长按或右键打开移除确认。长按松手不播放，滚动取消检测。移除只影响本地歌单，不删除源音频或修改网易云。导入确认与歌曲操作支持全局返回。

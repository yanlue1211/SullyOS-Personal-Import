# 临时朋友圈 API 监控

入口：朋友圈 → 设置 → API 调用监控。即使朋友圈已关闭，也可打开清理。

首次朋友圈请求起记录48小时，到期停止；可手动重新开始两天、清空记录，或关闭并清除。无额外巡检、模型调用或请求裁剪。只包裹朋友圈自身的社交活动、习惯评估、媒体识别；普通聊天和其他App调用保持原样。记录本地请求层的开始/结束、角色、用途、请求模型、服务主机、耗时、结果，以及接口返回的输入/输出/缓存 Token；未返回用量显示“—”。接口成功不等于活动一定落库，后者看原活动日志。

不保存API Key、请求/响应正文、URL查询参数或异常原文。输入构成只保留序号和字符数。独立 localStorage 键 `moments-api-monitor-v1`，最多200条，和朋友圈数据库、预算、记忆分离。清空/关闭增加代次，正在等待的旧请求不能把已清记录写回来。日志存储错误不会阻断或改变真实请求。

方便整体移除：删除 `features/moments/apiMonitor.ts` 和 `apps/momentsApiMonitor.tsx`，将 `features/moments/runtime.ts`、`media.ts` 的监控别名恢复为直接导入 `safeFetchJson`，移除 `MomentsApp.tsx` 的临时入口、状态及面板挂载即可。旧存储键可随之移除；无需迁移主库、记忆或备份格式。

# 表情包名称与发送失败状态

发送只在当前角色可见的表情库内解析。完整名称精确匹配优先；允许名称外引号、空白、全半角等格式归一化，但匹配必须唯一。显式分类前缀仅在对应分类内匹配，未知分类不跳到其他分类。没有同义词、子串、随机或模型二次选图兜底。

无法唯一匹配的指令保存为 system 未发送记录，原始名称仅保存在 emojiSendFailed 元数据中，不再保存为 assistant 的 `[表情：名称]` 气泡。一段输出中多次失败只显示一条状态，正常文字及有效表情按原顺序保留。

一句名称校验提醒放入已有 recencyTail、原响应原则之前，只在有可用表情且是聊天场景时加入。稳定段、共享规则、全局世界书、个人前缀、历史和缓存断点代码均不变。测试对比 5m/1h 转换结果，要求所有缓存前缀与断点内容逐字一致。

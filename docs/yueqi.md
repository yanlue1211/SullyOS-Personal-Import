# 月栖 · 睡前陪伴

入口：桌面「月栖」。角色选择沿用现有角色列表，月亮／小羊与鼠尾草浅绿主题。

## 内容和场景

「枕月听书」提供睡前故事、今日碎碎念、随便说说、自定义主题。先保存提纲，约每五分钟内容分批生成完整正文，再逐段合成并读取实际音频时长；全部成功才可开始播放。目标时长是估算，界面展示实际时长；不同角色、语言、TTS 韵律可能有明显误差，不保证精确分钟。完整故事不会因达到估算分钟数被截断。

「小羊夜话」使用绝对开始时间、累计暂停时长；角色播放、用户录音、输入、请求互斥。回复结束后重新计算下轮发言时间，不补播后台错过的多个轮次。逐渐安静的前四分之一正常，第二阶段缩短回复，后半程间隔加倍，最后四分之一停止自动发言，用户仍可主动接话。

两种模式均可选择「隔屏伴月」线上远程，或「月下相依」线下角色扮演。后者不默认同床或接触，不代写用户行为；场景随会话冻结、恢复和摘要保存，线下扮演不作为现实世界发生的见面。

## 上下文与记忆

每轮从数据库取角色，经 `loadCharacterContextRange` 和 `buildChatRequestPayload` 共用正常聊天上下文、世界书、召回、日程与情绪准备链。只替换 App 输出规则，不生成原聊天心声或调用其工具。角色／全局 API 整套选择不变，TTS 使用原服务商与角色音色。

睡眠日取用户设备本地日期，以06点分界，会话内固定。额外读取该日的日度记忆，以及记忆宫殿明确带有该日 `relativeTimeAnchor.dateKey` 的非群聊、未归档节点；无明确发生日期的宫殿节点不以创建时间冒充当日经历，仍由正常召回管线处理。

夜话超过24轮时，旧部分压缩为本场阶段摘要、保留最近12轮；完整原文仍在本地记录，不更改长期记忆。结束摘要只进入普通聊天一张有 `metadata.source='yueqi'` 和 `yueqiSessionId` 的文本卡，使用 `saveMessageOnce`，与现有消息和记忆提取兼容。卡片修改使用 `DB.updateMessage` 更新相同正文，不维护第二套隐藏摘要。已被长期记忆提取的旧内容不会被卡片编辑逆向改写。

## 播放与保存

`features/yueqi/runtime.ts` 是进程内单播放器；离开 App 页面不会卸载音频／调度器。新回复及取消均检查 AbortSignal；TTS 适配器本身不可中止时丢弃过期结果。分段全部成功后顺序播放，同一时刻只有一段角色音频。

会话、音频、音乐、偏好使用现有 assets 表的 `yueqi:*` 命名空间，不升级主库、不迁移旧数据。音频与文字分离；时钟检查点只写小记录，不反复写长音频。完整备份现有 assets 路径可保存恢复。清理月栖音频只清命名空间内音频，不删除共享 TTS 缓存、原聊天、背景音乐和文本摘要。文字与合成失败片段可重试；已有记录可另存为新创作。

背景音乐支持导入、单曲／顺序循环、独立音量、平滑压低和恢复、结束后继续或淡出、独立停止分钟数。音乐列表单独保存。数据 URL 音频的存储开销高于二进制；长时间语音注意设备配额，失败时保留已成功保存部分，不清库。

## 收音与平台边界

免手持默认关闭：点击开始，再点击结束，复用现有 `startStt`。开启后，角色声音结束缓冲800毫秒再收音，角色讲话时关闭麦克风。官方 ASR 使用月栖独立采样和停顿检测，约0.65秒以上有声、1.5秒停顿后提交，单段最长30秒；浏览器识别使用其原生端点判断。短促噪声可以过滤，但持续噪声、音乐回声和咳嗽仍可能误判，不能声称完全准确。识别失败关闭免手持并显示错误，不循环发送付费请求。

所有后台能力均待鸿蒙／Android／PWA／APK 真机验证。持续音乐在用户设备上的保活经验不是跨设备保证。后台定时请求、麦克风、双路音频、平滑音量仍可能被系统限制。故事已经准备完整缓存，但锁屏跨片段播放尚不能仅由前台模拟证明。

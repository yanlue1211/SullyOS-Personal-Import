# 主动消息 2.0 救援

当浏览器数据丢失而手边没有备份，可以从已更新的主动消息 Worker 导出它保存过的角色资料。可读内容取决于上一次同步，包括角色信息、世界书摘要、月度记忆与最近对话。救援文件保留原时间。常规导出只读取允许恢复的状态项和消息收件箱，并去掉配置类字段。

1. 在 Cloudflare 给这台 Worker 添加 Secret `AMSG_RESCUE_TOKEN`，使用至少 16 位随机字符。口令由账号主人保管。
2. 用浏览器进入自己的 Worker 地址加 `/rescue`，输入口令后下载 JSON。
3. 导出结束后从 Cloudflare 移除这项 Secret。开启期间定时投递和定时清理会暂停，关闭后恢复。
4. 打开糯米机「设置 → 备份 → 主动消息救援档」，选文件预览并保存。本机使用独立 IndexedDB 档案库，原有聊天和角色数据保留。可以直接阅读档案，也可以下载兼容 JSON。

导出与读取会留痕，系统会显示最近的开启或导出记录。口令只通过请求头发送，救援响应不保存到缓存。连续输入错误会暂时锁定。救援档内含私人对话，建议自行保管下载文件。

# 个人分支：主动来电与免手持

聊天加号中的「允许语音来电」「允许视频来电」按角色独立保存，默认关闭。权限仅允许弹出邀请；接听前不进入通话，不申请摄像头或麦克风。视频邀请接听后也由用户选择开摄像头。

角色正常回复或现有主动消息路径可以发送 `[[CALL_INVITE:voice]]` / `[[CALL_INVITE:video]]`。邀请指令在稳定系统前缀，只包含已授权类型。未接或拒接后可直接问原因，也可继续拨打，一切结合角色意愿、关系与情境；没有来电冷却。只限制一个同时响铃的弹窗和同一来源投递去重，不自动决定角色必须追打。现有主动消息总权限和调度设置仍生效。

邀请响铃 45 秒。超过 90 秒的离线旧投递不重新响铃。权限关闭和已有通话会终止来电邀请。通话结果写回角色记录，让后续回复知道是否接听。网页退出后的系统通知仍由现有推送负责，不提供手机原生电话权限，也不能保证后台页面被系统冻结时响铃。

通话界面的「免手持通话」每次由用户开启：说话后停顿约 1.4 秒自动提交，等待角色播放结束再继续听。真实语音沿用音频理解接口；原生 STT 沿用当前 STT 配置。切后台、输入文字、角色播放、设置弹窗暂停收音；关闭、结束或离开通话释放麦克风。浏览器权限、STT 可用性和实际手机噪声环境会影响效果。

## 剧情模式共享上下文修复

真实时间陪伴读取 `loadCharacterContextMessages` 的完整有效范围，尊重普通聊天条数、自适应水位线与用户断点，不再额外截成 100 条；本剧情镜像不重复注入，因为正文已有独立历史。虚构剧场保留独立条数和携带记忆开关。人物召回同时携带当前剧情最近消息，使本轮剧情输入成为主要检索线索；核心检索算法没有改动。共享音频转换为字幕/声音描述，心声保持未说出口的边界，真实时间按角色时间开关携带日期。

### 2026-11-03 通话录音与布局修正

录音参照已修好的月栖：使用 MediaRecorder 编码采集，Analyser 仅观察停顿，停止后沿用聊天的 WAV 转换。不再使用 ScriptProcessor 主线程拼接 PCM，页面渲染忙时不会由采样回调丢帧拼出破碎音频。月栖本身代码不改。

原生和音频 API 共用输入框旁的话筒，点击开始/再次点击停止。音频 API 识别结果放进输入框，可以修改后再发送；发送时保留原录音及声音细节。底部只保留输入显隐、挂断、外放，视频另加用户画面；识别方式下拉和免手持小开关共用一行。去掉通话里的大录音 Composer，语音头像、视频画面与消息记录按屏高分配空间，键盘/矮屏进一步收缩头像。


### 免手持唤起修正

收音准入判断实际原生播放状态、流式播放状态和进行中的请求，不再依赖可能滞留的 speaking 界面状态。角色选择页的隐藏设置不阻挡通话；隐藏输入区也不阻挡。已有草稿时会展开输入并说明原因，避免误删草稿。按钮区分打开麦克风、实际收音、识别发送与等待原因。实际录音开始回调触发“正在收音”，非仅开关亮起。停止/完成播放后可自动收音，停顿提交后等回复完成再重新收音。

来源标签清理支持半角、全角、双括号与 Markdown 外壳，作用于新回复解析、历史显示及朗读输入；不删除正常台词或声音表现标签。

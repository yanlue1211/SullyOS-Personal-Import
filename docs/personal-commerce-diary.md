# 模拟购物、外卖与角色个人日记

淘宝和美团外卖分别有独立桌面入口，共用本机订单引擎。只模拟，不连接真实平台、支付、地址、骑手或快递公司。

打开商城不会自动调用模型。点击逛一逛才调用全局 API，经过 ContextBuilder 的角色/世界书管线，生成商品后保存到 assets/personal_commerce_v1。刷新相同商城保留订单中的商品快照，不改变既有订单。

用户可给角色买、请角色给自己买、自己买。所有角色默认具备模拟自主购买权限，只能引用已保存商品 ID；一轮最多一单。同一角色72小时、跨角色24小时，以及未送达自主礼物拦截，使用 IndexedDB readwrite 事务串行决策，不靠提示词软限制。明确通过商城按钮请求的订单不受自主礼物冷却限制。自主购买不会另起定时 API，仅在正常聊天的角色回复中偶尔触发。

送达时间下单时固定，外卖15–90分钟，快递1–7天。状态由绝对时间差计算，不将进度当成真实平台物流。订单和通知待发送状态先持久化，卡片通过 saveMessageOnce 去重；失败与关页后下次扫描重试。网页开着每30秒扫描，回前台补扫。完全关闭不承诺实时推送。卡片记原定到达时间。

待收货摘要只在普通私聊里按角色注入生活背景，无待收货时不注入。已送达后停止常驻，历史订单卡仍按聊天历史范围读取。商品能力说明仅在已生成商品且自主礼物未处于冷却时加入，不在其他 App 的专用生成中加入。云端 fire_pack 不携带本机商品工具，不声称支持关页后的自主下单。

资产沿现有完整备份导出/导入。订单模型无需 IndexedDB 版本迁移。

日记保持原交换日记，同日期通过 DiaryEntry.kind='character' 另存个人日记，以 ID 打开、编辑和同步聊天，避免覆盖交换页。旧记录无 kind 视为 exchange。日记写作风格规则仅在点击生成时加入，不进入正常聊天常驻提示词。通常400–700字，服从角色性格，活泼角色可口语跳跃，不统一诗意化。生成读取所选日期及之前的记录，不将之后发生的消息写入过往日记。

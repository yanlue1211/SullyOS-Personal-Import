# 糯米机写歌 · Char 自主谱曲（独立验证分支）

## 接入范围
在原写歌页追加「自主谱曲」标签。仅新增 `features/songwriting/melody.ts`、`components/song/MelodyPanel.*`，复用原 `songs` 存储事务与聊天请求/记忆召回；仅对 `utils/audioApi.ts` 追加一个独立试听方法，不修改原「一起听」提示词。不要合并到与其他写歌窗口冲突的分支，先核验运行版本。

首次限定 C 大调、4/4、八小节、50–160 BPM，模型输出精确音符、时值和可选歌词音节，经严格校验后写入 `song.melody.versions`；修改只允许 patch 指定小节，其他音符原样保留。版本不丢失；旧版可以选中并恢复为当前版。未收到完整有效谱则不写入。

每个有效版本可：
1. 用 abcjs 6.7.2 绘制五线谱；
2. 在用户点击后，使用 CreateSynth 在浏览器合成 WAV（注意 `CreateSynth.download()` 返回临时 Blob URL，不是字节数组），生成本地试听链接；
3. 用 `getMidiFile` 生成 MIDI；可点击页面内下载链接，非永久公网直链；
4. 由用户**明确点击**向独立音频 API 发送该版本的 WAV，使用纯客观声音提示词（不打分，不提修改建议，不夸大）；
5. 保存客观分析文字到对应的版本；Char 下一次谱曲请求读取原谱和该客观描述，由 Char 自己决定保留还是局部调整。

WAV 当前为运行时临时资源（不重复写入音频存储）；可根据已保存在歌曲内的音符随时重新合成，因而文字与媒体备份都保留可再生的谱。尚未做跨会话有效的 WAV 外链/海绵旋律上传，后续可把 Blob 交给独立上传适配层。

## 技术与风险
- 这是**验证性试用**，不是已成功部署或实测连接。
- abcjs 库使用版本固定的 jsDelivr 脚本以避免触碰 pnpm 锁文件，首次加载依赖外网；音色默认从 GitHub 远程 soundfont 下载。用户手机 HarmonyOS 7、永恒浏览器、PWA、APK 都需要真机验证；确认稳定后应该改成随包发布的 npm / 本地声库。
- `AudioContext` 必须在用户点击时创建；不同手机对音频上下文/内存有差异，长曲优先限制长度。
- abcjs 不生成歌唱人声，钢琴音色播放的是**人声主旋律**，不是最终人声或伴奏。
- 仅支持八小节片段；中文咬字、人声演唱效果、海绵是否准确遵循旋律均没有实测，不能宣称已实现。
- 单版本已经听过则复用缓存说明，避免重复花费音频模型额度；生成主模型沿用当前 Char 的聊天 API，不擅自调用昂贵备用模型。
- 此功能不改现有 Lite，不改记忆核心、不迁移原数据、不删除其他写歌入口。

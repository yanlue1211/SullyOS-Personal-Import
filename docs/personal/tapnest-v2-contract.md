# TapNest独立App与AutoJs6 V2实现记录

基线：SullyOS personal/audio-listening / 9ab76e84；原生模型格式参考TapNest personal/motion-v2-20261112 / fc34602。原生APK、Lite、Worker和原记忆算法不改。

- 独立App负责模型导入、按Char绑定与形态/两套台词/API/定时设置。`TapNestGate`在配对后才懒加载常驻Runtime，不依赖Chat组件挂载。聊天加号进入独立App，旧桥接源码保留。
- PNG单宠ZIP支持rig.json、forms.json和tapnest-pet.json；原ZIP和图片进入原blob资产库，描述进入assets，索引/导入事务提交。校验路径、画布、父图层环、体积与骨链数量。多形态台词空数组不回退通用台词。保留导出的跨形态配件覆盖，按原生分类更换真实配件，连同来源动作帧和骨链组合；关联图层不完整时提示。
- 网页与AutoJs6共用portable PNG播放器；支持父图层变换、镜像、动作帧、身体关联服装、基本动作、区域多骨链/柔性、呼吸和拎起图。与Kotlin绘制并非逐像素同一实现；需真机验收，不声称全量原生视觉等价。
- V2绑定127.0.0.1:18347，仅指定Github Pages origin；PIN每次启动变化，6次失败锁定至重启，随机会话令牌。分片上传只传公开配置和模型图片，不传提示词、API密钥、角色记忆或历史。最多48MiB字符，顺序及完整性校验后提交；播放器回报正确revision加载完成才显示同步成功。
- 包含charId、formId、revision和事件id；真实输入、戳动段、timer、form/wardrobe、feed/bath事件。API处理前原子claim，失败/中断不自动重复付费调用。成功结果可复投但不再生成。旧角色/旧形态/旧revision的回复不发到新桌宠。
- 自动触发由AutoJs6执行，固定模式本地抽取，与网页无关。API定时仅网页近期在线时排队，30秒过期；用户输入/请求中/刚互动跳过，不补发。故障或断线不回退昂贵主模型。
- 戳动按小于3秒连续计数，停止超过3秒后整段一次请求。最低次数留空等于1；填3则至少3下。戳动时先预设；请求中继续戳，下一段等待本轮结束和再次停顿3秒，不打断、不并发。第5下起已配置的生气图片生效，第6下及以上请求增加次数/表情约束。
- `…`单独状态，与预设气泡共存；请求成功/失败或切换模型后结束。原生等待180秒有明确超时提示。
- API使用原角色上下文构建器、世界书/记忆召回和API选择。消息落原messages，真实输入是user、互动/定时是system、生成是assistant；固定台词不伪装模型发言。不另建记忆提取。向原amsg状态同步标脏，保持云端上下文可刷新。
- 完整备份沿用原资产/Blob旁路；文字配置/index加入既有activityTextAssets白名单并受personal保护，媒体恢复不覆盖配置。文字恢复可缺素材，用户补原ZIP。

验证包括实际ZIP导入、原子claim、独立API失败不回退、事件去重、设置切换拦截、HTTP协议UTF-8分片、角色/形态路由、定时离线与过期、连续戳动边界、正在输入与预设共存、模型绘制/衣服/生气帧、多骨链有限几何、Kotlin省略默认字段和原缓存/备份回归。没有调用用户付费模型。

容器禁止本地Chromium的socket，远程浏览器也无法访问本地验收服务；因此未把自动检查冒充手机真机验收。原生悬浮/键盘兼容处理保留自已验证的AutoJs6 V0.15，仍需要用户手机实测。

发布前本地结果：桌宠专用40项通过，含缓存/备份/聊天入口的扩展回归128项通过，生产构建通过；未执行用户付费API。

交互：快速双击（<300ms）打开输入，慢戳计数。静止长按1秒松手打开分层设置，按住5秒仍由原生关闭；输入、设置和分层内容按visualViewport高度收纳并内部滚动。形态/配件/生活互动是不同页面，食物与洗澡再入子页；无常驻聊天按钮。进食和洗澡预设可分别配置，API开时以明确system互动事件进入原角色管道，不编造用户发言。

# 桌宠使用教程 · TapNest → 糯米机 → AutoJs6

## 先分清三个地方

- **TapNest**：画好的PNG素材在这里组合、绑骨、调动作、制作多形态。
- **糯米机里的「桌宠」App**：导入成品、绑定Char、切换形态、设置API和台词。
- **AutoJs6**：让桌宠出现在手机桌面和其他App上。它继续负责悬浮与互动，不会改成只在糯米机里显示。

这次不用更新TapNest APK，也不用更新主动消息Worker。旧AutoJs6脚本不能直接使用新连接，需换成V2。

## 第一次使用：先不开API

1. 打开TapNest，把这只桌宠和各个形态做好。在TapNest中选择**导出单只桌宠ZIP**。不要选「全部桌宠备份」。当前支持PNG分层模型，不是Live2D包。
2. 打开糯米机桌面的**桌宠**App。聊天加号里的「桌宠」也可以进入。
3. 在「角色与模型」中选要绑定的Char，点**导入TapNest单只桌宠ZIP**，选择刚导出的文件。
4. 在「成品模型」中选它，在「当前形态」中选默认形态。已有多形态会一并导入，不用再制作一次。
5. 先保持「接入API与角色记忆」关闭，在预览里看图片、动作和形态。预览不调用API。
6. 检查这一个形态的戳动台词，每行一句。原本在TapNest设置的形态台词会保留；也能在糯米机另改，不影响TapNest原包。切换到其他形态后可分别修改。
7. 点**保存并使用「角色名」**。同一成品包可以给不同Char使用，绑定和设置分别保存；手机桌面当前显示一个角色。

如果TapNest中用了跨形态配件混搭，请先在TapNest把想要的组合存成独立形态，再导出。完整形态可以切换，网页端暂不重新组合跨形态配件。

## 让它显示在手机桌面和其他App上

1. 到AutoJs6的任务列表，**停止旧版桌宠脚本**。不要同时开两个桌宠连接脚本，否则会占用同一端口。
2. 回糯米机「桌宠」App，点**桌面连接 → 下载AutoJs6 V2脚本**。
3. 在AutoJs6打开这个`.js`文件并运行。若弹出悬浮窗授权，允许后回到AutoJs6再运行一次。
4. 第一次运行需要联网下载播放器。下载完成后，桌面上会出现等待同步的透明悬浮窗口；AutoJs6日志/提示中会显示**六位配对码**。
5. 回到糯米机「桌宠 → 桌面连接」，输入这六位码，点**连接并同步桌宠**。
6. 如果浏览器询问是否允许访问本机/本地网络，允许。看到**已连接 · 模型与设置已同步**，表示模型传输和桌面播放器加载均已确认。
7. 现在可以离开糯米机，去手机桌面或打开其他App，桌宠仍由AutoJs6显示。

不需要无障碍权限，不需要录屏/截图权限，也不用把API密钥填到AutoJs6里。配对码每次启动会变化，只在本机连接。

## 怎么互动

- **戳一下**：播放桌宠动作，并显示当前形态的戳动预设。
- **拖动**：移动悬浮窗，支持已导入的拎起图片。
- **切形态**：用桌宠下方的形态下拉框。连接着糯米机时会回传保存；也可回糯米机App选形态后保存。
- **点💬**：API开启时打开输入框，输入后点发送。
- **“…”**：角色正在生成回复。期间继续戳可以显示预设，思考标签仍保留。回复到达或失败后替换状态，不会让你一直看不出有没有在处理。
- **按住不拖动5秒**：关闭桌宠。也可以到AutoJs6任务列表停止脚本。
- **糯米机里的断开连接**：只断开API通信，不等于停止AutoJs6本地桌宠。

## 开启API和角色记忆

1. 在「角色与模型」确认当前绑定的Char。
2. 打开**接入API与角色记忆**。
3. 不勾「使用桌宠独立API」：沿用这个角色的对话API，角色没有独立配置时沿用全局配置。
4. 勾选后填写独立的**接口类型、API地址、Key、模型名**。不完整或调用失败会提示，不会自动改用主模型。
5. 可以修改「桌宠状态提示词」，默认会说明：本次回复显示在桌面气泡里，但没有屏幕信息时不能声称看见你在做什么。
6. 点**保存并使用**，等待同步完成。

API对话读取这个Char原有的人设、世界书、上下文和记忆。真实输入、API回复以及相应桌宠事件保存在同一角色消息中，作为原有记忆整理的材料；不会另建记忆库，也不保证每次互动都被长期记住。原生私聊不会额外再回复一次。固定台词在AutoJs6本地显示，不每次往私聊刷一条记录。

## 连续戳动怎么请求API

只有「API开/关」这个总开关，没有额外的省API模式。

API关闭：无论怎么戳，都只说预设，不调用模型。

API开启：

1. 每两次戳动间隔小于3秒，算同一段。
2. 正在戳时先播放预设，不在第3、第6下中途各请求一次。
3. **停手超过3秒**，才把整段总次数交给模型，一段只请求一次。
4. 「每段至少戳几下才回应」留空：哪怕只戳1下，停手超过3秒也会请求。
5. 填3：这一段达到3下、并停手超过3秒才请求；只戳2下不会请求。
6. 思考中继续戳：不打断、不并发，继续显示预设并按3秒间隔记录新段；上一轮结束后，还要确认这一段已停手超过3秒和达到最低次数，才发下一轮。
7. 连续第5下起，播放你在TapNest配置的「连续戳动生气」图片；如果没配置图片，不会凭空制造素材。第6下及以上的请求会同时带上累计次数与相应表情提示，要求回应与表情协调。

次数指**本次请求对应的那一段**，已经发出的请求不会在思考途中偷偷改写。切换角色、模型或设置后，不投递旧角色/旧形态的回复。

## 每隔X分钟自动发言

1. 打开「每隔一段时间主动发言」，填分钟数。
2. API关闭时：从当前形态的**定时固定台词**抽一句。它与戳动台词分开设置，留空则保持安静。
3. API开启时：读取角色上下文，生成一次桌宠主动发言。
4. 正在输入、已有请求或刚发生互动时跳过这次。断线时不堆积定时请求，恢复后不补发一串。

## 后台与断线

- 切去糯米机内部其他App，桌宠连接继续运行，不需要聊天页一直打开。
- API对话需要糯米机网页和AutoJs6都还在运行。建议沿用你原本能保持浏览器活动的悬浮窗方式。
- 浏览器被系统杀掉后，AutoJs6的本地动画、形态和固定台词定时可以继续；API对话不能凭空继续。
- AutoJs6重启后可恢复已同步的本地模型；首次下载后也会缓存播放器。需要API时重新输入新的六位码配对。

## 常见问题

**连接失败**：先确认运行的是V2、旧任务已停止、六位码是这次启动显示的，再检查浏览器是否允许本机网络访问。

**模型已传输但没确认加载**：查看桌面气泡和AutoJs6日志；模型可能有图片缺失或体积过大。先在糯米机预览，保留原ZIP后重新导入。不能把“传完了”当成“显示成功”。

**API失败**：打开桌宠App看原因，核对URL、Key、模型与接口类型。失败不会自动重试付费生成，需你重新发送。

**生气表情没有变化**：在TapNest给这只桌宠配置连续戳动生气帧后，重新导出并导入。预设台词和图片是分开配置的。

**网页播放与APK不完全一样**：两者使用不同渲染环境，新网页播放器需要真机验收。先看预览，再核对手机悬浮效果；旧脚本和原ZIP都保留，不覆盖原APK模型。

## 更新模型与备份

素材或动作仍回TapNest修改。导出新ZIP后，在糯米机导入为新成品，再给角色重新绑定；旧模型保留，不自动覆盖。

完整备份包含桌宠模型、素材与设置。文字备份保留绑定和设置，恢复后需补回模型素材；可以再导入原ZIP。请继续保留TapNest原始压缩包。
